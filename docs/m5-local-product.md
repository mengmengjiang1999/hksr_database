# M5 本地产品化实施报告

> 状态：本地可运行版本完成
>
> 日期：2026-09-02

## 1. 阶段结论

M5 已把 M1–M4 的领域能力接入本地 FastAPI 应用和单页 Web 界面，形成完整的玩家使用闭环：

```text
玩家问题 → 混合检索 → 受证据约束的回答
                      ├→ 主张下方的官方原文与相邻上下文
                      └→ 已审核、带证据的一跳关联
```

服务默认监听 `127.0.0.1`，读取知识或状态不会触发抓取、解析或索引写入。数据同步只能通过显式管理 POST 发起。

## 2. 本地使用

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e .
.venv/bin/python -m app.cli initialize
.venv/bin/python -m app.cli serve
```

浏览器打开 <http://127.0.0.1:8000/>。当前版本没有账号和鉴权，不应监听公网地址。

## 3. API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/ask` | 返回状态、回答、逐条主张与引用 |
| `GET` | `/api/search` | 混合检索官方证据 |
| `GET` | `/api/sources/{id}` | 查看来源和文档结构 |
| `GET` | `/api/entities/{id}` | 查看实体、别名和审核关系 |
| `GET` | `/api/relations` | 查询默认可见关系 |
| `GET` | `/api/admin/status` | 查看全管线数量和失效审计 |
| `POST` | `/api/admin/sync` | 显式执行采集与索引更新 |

FastAPI 自动接口文档位于 `/docs`，OpenAPI 描述位于 `/openapi.json`。

## 4. 页面与证据策略

- 回答状态区分官方原文、证据推理、资料冲突和无法确认；
- 每项主张独立显示支持检查和自己的引用，不使用模糊的段尾来源列表；
- 引用可展开查看原文、相邻上下文、来源类型、版本、语境及官方链接；
- 只展示 `approved` 且证据仍有效的关系；
- 关系证据等级、方向和谓词使用中文产品文案；
- 页面不会用模型常识补齐知识库里不存在的事实。

## 5. 验证结果

自动化测试共 46 项，覆盖 API 参数校验、问答证据、来源与实体浏览、关系可见性、只读状态、显式同步和静态页面结构，全部通过。

真实浏览器烟测覆盖：

1. 首页及健康状态加载；
2. 提交“小三月的纯真有没有失去？”并获得官方原文回答；
3. 展开姬子角色语音引用，查看相邻上下文和官方 Wiki 链接；
4. 提交阿格莱雅问题并显示审核通过的一跳关联；
5. 打开管理状态，确认本地库有 5 个来源、41 个片段、35 个实体、8 条审核关系、308 条待审核候选和 0 条失效关系。

## 6. 已知限制

- 当前回答为证据抽取式原型，还没有接入受约束的大模型归纳器；
- 管理同步在请求内同步执行，长任务尚无后台队列和进度推送；
- 管理状态是开发者视图，待审核关系尚无可视化审核操作；
- 本地版本没有认证、多用户并发保障和公网部署安全设计；
- 数据仍是阶段验证样本，不代表官方资料全量覆盖。
