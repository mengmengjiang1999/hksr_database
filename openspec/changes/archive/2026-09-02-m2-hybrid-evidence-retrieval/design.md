## Context

M1 已有 FTS5 和 41 个官方证据片段，但精确短语检索不能稳定覆盖中文自然语言改写、别名和多来源过滤。

## Goals / Non-Goals

**Goals:**

- 完全本地、可解释地召回候选证据。
- 支持实体别名和来源语境过滤。
- 用固定标注集量化 Top K 与无答案表现。

**Non-Goals:**

- 生成答案、自动断言实体关系、训练神经网络模型。

## Decisions

- 用字符 2/3/4-gram TF-IDF 建立零依赖语义基线，后续可替换 embedding。
- 人工维护实体与别名，玩家俗称只参与问题理解。
- 混合分数保留词面、语义、实体、栏目和来源质量分量。
- 在排序前应用来源类型、版本和语境过滤。
- 仅从明确 `角色：台词` 标签提取说话人，不推断省略主语。

## Risks / Trade-offs

- 小样本容易高估召回率 → 报告同时记录样本规模和全量门槛未满足。
- TF-IDF 不理解深层语义 → 保留独立模式评测与可替换向量接口。
- 人工实体清单覆盖有限 → JSON 清单可审查并随语料扩充。

## Migration Plan

扩展现有 SQLite 表；强制重解析为 500 字片段；重建 FTS、实体链接和向量；运行三种模式评测。索引均可从文档表重新生成。
