## Context

领域能力已经由 CLI 验证，但没有稳定 HTTP 契约和面向玩家的本地界面。当前运行环境需要安装 Web 依赖，且第一版必须避免误监听公网。

## Goals / Non-Goals

**Goals:**

- 用 FastAPI 暴露 M1–M4 能力。
- 提供引用、上下文、关系和状态可视化。
- 具备可测试的本地启动与初始化流程。

**Non-Goals:**

- 公网部署、账号、权限、多用户并发和后台任务队列。

## Decisions

- 使用应用工厂注入数据库与数据路径，测试可使用临时数据库。
- UI 使用单个原生 HTML/CSS/JS 页面，无 Node 构建依赖。
- `serve` 默认绑定 `127.0.0.1`，修改主机需显式参数。
- 管理同步为独立 POST；问答和浏览接口只读。
- 路由调用领域模块，不复制证据或关系判断逻辑。
- 使用 FastAPI、Uvicorn 和 HTTPX 最小依赖组合。

## Risks / Trade-offs

- 同步请求为同步阻塞操作 → 本地小规模可接受，在线版改为任务队列。
- 无身份验证 → 默认仅回环地址；文档警告不要暴露公网。
- 单页原生 UI 可维护性有限 → MVP 优先，后续再选前端框架。

## Migration Plan

创建虚拟环境并安装项目；运行初始化命令构建索引和关系；启动回环地址服务；用 API 测试与浏览器烟测验证。CLI 能力保持不变。

## Open Questions
