## Context

M0 已确认官方 Wiki 与米游社存在可用 JSON 接口，但不同页面使用 RPG 模板、HTML 页签或文章结构。系统要求所有证据可追溯且本地可重复构建。

## Goals / Non-Goals

**Goals:**

- 建立幂等、增量、可诊断的数据管线。
- 隔离非剧情编辑性内容。
- 任意片段可回到来源、栏目和原始响应。

**Non-Goals:**

- 全站采集、答案生成、关系推断、在线视频字幕识别。

## Decisions

- 使用官方 JSON 接口而不是渲染 HTML，以保留结构化字段。
- 原始响应保存为文件，规范化数据保存到 SQLite，兼顾调试和查询。
- 使用稳定字段生成内容指纹，忽略浏览数和签名 URL 等易变字段。
- 用 `(provider, external_id)` 去重，替换式解析避免旧片段残留。
- 先用 SQLite FTS5 trigram 建立中文检索基线。

## Risks / Trade-offs

- 接口无稳定性承诺 → 保留原始样本、错误状态和回归测试。
- 模板字段可能混入内部元数据 → 使用字段黑名单并隔离编辑性栏目。
- 视频缺少机器字幕 → 明确记录能力缺失，不伪造文本。

## Migration Plan

初始化 SQLite；发现来源；抓取并解析五个固定样本；重建 FTS；重复运行验证幂等。失败时可删除本地生成数据库并从原始响应重建。
