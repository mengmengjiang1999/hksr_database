# Explore: M1 本地数据管线

## 问题边界

官方 Wiki 和米游社文章结构不同，页面又依赖动态接口。M1 必须先解决来源身份、正文解析、增量更新和证据追溯，不能同时承担问答生成。

## 方案比较

- 直接抓 HTML：容易受动态渲染和页面壳影响，不采用。
- 使用站点 JSON 接口并保存原始响应：结构更稳定、可回归，采用。
- 每次全量重建：实现简单但浪费网络请求，改用稳定内容哈希。
- 引入外部数据库：本地 MVP 没有必要，采用 SQLite 与 FTS5。

## 结论

将发现、抓取、解析、索引拆成独立幂等命令；正式证据只接受官方身份可验证且栏目符合白名单的内容。原始响应留在本地，不提交 Git。
