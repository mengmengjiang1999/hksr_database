## Why

M7 的云端采集需要数天才能补齐资料，但现有单页原型已经拥有可用的证据检索接口。现在应先建立不依赖采集完成度的只读用户界面，让新增数据自动改善搜索结果，并把后续 SQLite 到 RDS 的切换隔离在稳定 API 之后。

## What Changes

- 将当前问答原型扩展为可导航的问答、搜索、资料来源和数据覆盖状态界面。
- 为搜索结果增加资料类型、上下文和版本筛选，并为结果提供可追溯的来源详情入口。
- 提供面向用户的只读资料目录元数据与覆盖统计，不在浏览页面触发采集或索引写操作。
- 明确定义加载、空结果、证据不足和请求失败状态，并完善移动端布局与无障碍语义。
- 保持 UI 仅依赖稳定 HTTP API，使采集进度、增量版本更新及未来 RDS 读取层切换不要求重建前端。

## Capabilities

### New Capabilities

- `knowledge-browser-ui`: 覆盖可导航的证据问答、筛选搜索、来源详情、覆盖状态和响应式交互。

### Modified Capabilities

- `local-knowledge-app`: 扩展只读浏览 API，提供搜索筛选目录和面向用户的覆盖摘要，同时保持读取请求无副作用。

## Impact

- 主要影响 `web/index.html`、`app/api/main.py` 及 API/UI 回归测试。
- 不改变 M7 采集服务、OSS 原始层或现有 SQLite 数据；后续 RDS 适配需维持本变更定义的响应契约。
- 第一版仍为私有部署准备，不在本变更中增加公网开放、账户系统或大模型生成。
